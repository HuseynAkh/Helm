**Data flow**

1. A toolbar/sidebar/menu/item action reaches ContentViewController through window, split, and tab forwarding. Navigation standardizes/validates the URL, exits search, updates history, and starts a cancellable load task. `Windows/MainWindowController.swift:210`, `Windows/MainSplitViewController.swift:38`, `Controllers/ContentViewController.swift:124`, `Controllers/ContentViewController.swift:259`.

2. DirectoryViewModel asks the filesystem actor for a complete listing. The actor prefetches metadata, skips unreadable entries, optionally caches the array, and reapplies star state. DirectoryViewModel uses a generation and URL check before committing the result. `ViewModels/DirectoryViewModel.swift:38`, `Services/FileSystemService.swift:17`, `Models/FileItem.swift:27`.

3. The controller explicitly reloads AppKit, starts monitoring, records folder access, and publishes the active location to tab/sidebar/breadcrumb. These are separate steps rather than one atomic presentation-state commit. `Controllers/ContentViewController.swift:270`, `Controllers/ContentViewController.swift:305`.

4. Search uses a separate MainActor service and AsyncStream, but its results overwrite `directoryViewModel.items`. Recent also overwrites that same array while preserving another directory as the operation destination. There is no distinct directory/search/recent presentation model. `Controllers/ContentViewController.swift:315`, `Controllers/ContentViewController.swift:359`.

5. Widget selection flows to `selectedItems`. The reverse path is absent: publishing selected URLs does not select widget rows/items. Most file commands then resolve URLs against `displayItems`, excluding expanded descendants. `Views/AppKit/FileGridView.swift:133`, `Views/AppKit/FileListView.swift:273`, `Controllers/ContentViewController.swift:649`.

6. A successful mutation returns source/destination arrays, registers undo, then refreshes the directory model and view. Drag/drop bypasses this common completion path. `Services/FileOperationService.swift:39`, `Controllers/ContentViewController.swift:405`, `Views/AppKit/FileListView.swift:359`.

**Threading and concurrency**

- **Actors:** FileSystemService, FileOperationService, FileMonitorService, PathCompletionService, and RecentItemsService serialize their own state. - **Task structure:** Navigation, search, debounce, monitoring, rename, and drop operations use stored or unstructured Tasks.
