# Next for Helm's AI mode

Huseyn's list of what to build next, kept on 2026-11-15. Nothing here is built yet.

1. **This Folder / Whole Mac.** A switch in the AI panel's folder row. Whole Mac lets the model see the home folder (Desktop, Documents, Downloads, Pictures, Movies, Music, iCloud Drive) and mounted drives, and propose moving files to where they belong. System folders, Library and other apps' data stay out. The consent line names the home folder while it's on. Every plan still waits for Apply, and one Undo puts it back.
2. **Read contents.** A switch for both the AI panel and AI search, so they can read what's inside files: text in PDFs and documents, text and objects in images, and video (frames sampled on this Mac, and speech if it works well). Reading happens on this Mac with Apple's frameworks, and the model gets short summaries, never the files. Cloud-only files are never downloaded. With LM Studio or Ollama nothing leaves the Mac; with a cloud provider the consent line says summaries are sent while the switch is on. This changes the "never file contents" promise, so the wording is Huseyn's call before it ships.
3. **File type in AI search.** With AI search on, pick a kind first: Photo, Video, Document, Folder, Code, Audio or Archive.
4. **Panel resizing.** Dragging the AI panel's edge doesn't resize it properly in a real window. Find out why and fix it.
5. **A lighter panel.** Restyle the AI panel so it feels like a Mac app and fits Helm's Nautilus look, not a code editor: system materials, softer bubbles and cards, native type and spacing, in light and dark.
6. **A new AI mark.** One continuous looping line with a soft gradient on no background, in the spirit of the Apple Intelligence mark but Helm's own shape (a wheel rosette is the first idea). Draw a few options for Huseyn to choose from, then use the chosen one everywhere: the header, the search field, the panel, the AI Mode screen, the Settings tab, the banner, docs/brand and every README picture.
